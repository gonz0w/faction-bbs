354 Rust tests per OS and 130 host Python tests pass.

coalescing, opt-out/reconnect, partial menu input, arrow focus, partial escape

input, terminal settings/synchronized-output probes, explicit outgoing answers,

are escape-free; the native client's existing final device-side cursor/style reset
after logout is recorded separately. Cooldown/expiry timestamps are aged only in
owned synthetic fixtures; short idle observations use real waits.

real waits over 66 seconds per OS. The shared eight-control regression includes
three real 66-second menu/composer/Lua waits. Existing terminal/art/editor/social
regressions and twenty complete-recovery controls per OS also run. Current native
inputs and installed Rust/C door binaries match their tested source/build hashes.

poll per two seconds and eight ID/state keys. No new thread, SQLite connection,
listener, dependency or schema; schema remains 17. Existing credential, helper,
session, output and deadline budgets remain. Optional consent resets every login.
