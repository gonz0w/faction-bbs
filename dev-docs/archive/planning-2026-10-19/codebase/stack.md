# Stack Map

## Current State

No technology stack is implemented or selected. The only project content is the two Markdown design inputs in `docs/`.

## Declared Constraints, Not Selections

The PRD offers Elixir, Go, and Node as examples of real-time-capable backends; PostgreSQL or equivalent storage; a reactive web frontend; REST/WebSocket APIs; plugins; scriptable shells; and homelab-friendly deployment. The transport design names IP, Reticulum, mesh networks, anonymity networks, overlays, and packet radio as candidate transport families.

These are research inputs only. A later comparison must demonstrate real-time and persistent behavior, constrained-link operation, terminal compatibility, self-host deployment, and adapter isolation before adopting technologies.
