# Integration Map

## Current State

No integrations are implemented, installed, configured, or verified.

## Future-Facing Boundaries

The seed documents identify potential IRC clients, import/export, AI agents, door-style applications, third-party plugins, REST/WebSocket consumers, backup tooling, and multiple transport families. All are candidates, not commitments.

Future architecture must keep transport behavior outside the core and treat client bridges, imports, extension APIs, and agent integrations as separately permissioned, failure-isolated boundaries.
