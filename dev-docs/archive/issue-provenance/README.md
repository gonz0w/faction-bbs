# Historical issue migration provenance

These unchanged files record the original BG/BBS IDs and their initial GitHub
mapping. They contain no authoritative task state, current priorities or work
instructions. Live scope, plans, dependencies, tests and completion are exclusively
in [GitHub Issues](https://github.com/gonz0w/faction-bbs/issues).

Execution plans, the roadmap and first-slice sequence were retired under #181.
Their original text remains in Git history; no new local task tracker replaces them.
The existing planning/source archives and measured evidence remain immutable.
