# Security policy

Faction BBS is in architecture research. There are no releases, supported product versions, or production deployment instructions. No security assurance is claimed for future implementations or experiments.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/gonz0w/faction-bbs/security/advisories/new) for security-sensitive findings. Do not open a public issue containing an exploit against a live system, credentials, private addresses, user messages, or personal data. Include affected files/revisions, a minimal sanitized reproduction, likely impact, and any proposed mitigation. No response-time or support commitment is established yet.

The [project security/privacy requirements](docs/security-privacy.md) describe the intended boundaries. Approval bypasses, unintended exposure, leakage from local-only data/channels, file-handling bugs, terminal-control injection, and unsafe door runtimes are especially relevant.

Future releases must define supported versions, update guidance, and a tested security baseline before being described as production-ready.
