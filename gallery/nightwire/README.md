# Nightwire gallery pack

Original Faction contributors' ANSI/ASCII art, distributed under the included
BSD-3-Clause LICENSE. This pack makes no archival ACiD/iCE/Razor rights claim.
The coordinated dark lettering, split-wing sigil and carrier pages replace the
earlier skyline/receiver; all three ANSI/text pairs are regenerated with the
[theme source](../../tools/build_nightwire.py).
Use `faction gallery-check gallery/nightwire` before configuring it. Canonical
sixteen-row pages use the existing importer; text editions remain available.
See [the gallery guide](../../docs/scene-gallery.md) for curation and removal.
